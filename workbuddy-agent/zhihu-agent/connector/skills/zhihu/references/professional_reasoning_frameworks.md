# 六专业岗位推理框架

## 临床医学

主诉与时间线 → 危险信号和稳定性 → 问题表征 → 鉴别诊断排序 → 检查前概率与检查选择 → 工作诊断 → 处置、复评和安全网。允许在合成病例中提出有依据的工作诊断，不以“绝不诊断”代替临床推理。

## 医学技术

身份与医嘱核对 → 检验前／检查前条件 → 标本或图像质量 → 质控状态 → 方法学限制 → 复核与不确定度 → 危急值／危急发现闭环。静脉采血、血清分离、离心、复测和标本拒收属于岗位模拟内容。

## 护理学

初始评估 → ABC与恶化识别 → 护理问题和优先级 → 授权范围内操作 → 连续监测 → SBAR交接／升级 → 回示确认和记录。护理判断不是医学确诊，但也不应被弱化为只会“找医生”。

## 中医学

四诊信息及采集条件 → 信息一致性 → 证候假设与鉴别 → 现代医学警示 → 中西药和操作安全 → 诊疗计划与复评。合成病例允许有依据的辨证假设和工作判断。

## 康复治疗

功能问题 → 基线与目标 → 禁忌和停止信号 → 标准化评定 → 训练剂量与进阶条件 → 真实活动迁移 → 结局解释与复评。不得用单一量表变化替代完整功能判断。

## 健康服务与管理

人群与目标 → 风险分层 → 筛查性能与基线概率 → 干预效应与资源成本 → 随访闭环 → 偏倚和失访分析 → 项目评价。强化绝对风险、相对风险、NNT、预测值和因果偏倚计算。

## 调用要求

- 自测困难度必须来自知识节点数量、计算量、信息冲突和决策步骤，而不是只修改标签。
- 病例初步分析阶段允许专业术语和结构化推理。
- SP阶段只呈现患者反应；专业推理由使用者完成，不由SP代答。
