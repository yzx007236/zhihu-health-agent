# 合规、分流与固定文案

> 本文件内容已在《队员必读与开发分工》第 12 节确定，可直接引用，不随评分表冻结而变。

## 1. 四条不做（安全边界）

1. 不诊断真实个体，不下疾病分级结论。
2. 不推荐具体药物、剂量，不建议自行停药、换药或调药。
3. 不承诺治疗效果，不推荐保健品或偏方替代正规治疗。
4. 不采集、保存或展示真实患者个人健康信息。

以上限制只针对**真实医疗请求**。进入工具确认的合成病例 `dialogue` 阶段后，属于岗位模拟：临床医学和中医学角色可以基于病例证据提出鉴别诊断、工作诊断、检查计划和风险处置；护理、医学技术、康复和健康管理角色可以执行各自权限内的专业判断与操作。静脉采血、血清分离、标本复核、护理评估和康复评定等训练行为不得仅因含专业术语而触发分流。

合成训练仍禁止：无证据宣布确定诊断、超出当前虚拟岗位权限、给现实人物开具具体药物剂量、承诺治愈或把训练输出用于现实诊疗。

## 2. 固定分流

用户要求真实诊断、用药调整或治疗方案选择时，不进入生成式建议流程，返回固定提示：

> 这个问题涉及真实医疗决策，超出本学习工具的范围，请咨询具备执业资质的医务人员。如遇紧急情况，请立即拨打 120。

不得仅凭“采血、血清、检查、诊断、处置”等关键词触发上述文案。必须同时存在真实人物、真实报告、现实可执行请求或可识别健康信息；已确认的合成病例默认继续训练。

## 3. 固定展示（安全提示必须与反馈内容同层可见，不得藏底部/需滚动）

- **首页**：本产品为教学训练工具，所有病例均为合成案例，不构成医疗建议，不用于真实诊疗。
- **对话页**：训练场景·合成病例·不构成医疗建议。
- **报告页**：本反馈仅用于课程学习与能力训练，不构成对任何真实个体或病例的医疗建议；评分不代表临床能力认定。

## 4. 知识库未覆盖时的固定话术

> 当前课程知识库未收录这一问题的可靠依据，请查阅课程指定教材或向教师咨询。

## 5. 数据与内容合规

- 病例、日志、演示账户全部使用合成数据。
- 用户输入真实姓名、病历号、报告照片等信息时，提示勿输入，不保存、不进入评分。
- 知识卡、病例和评分口径保留版本记录。
- 第三方资料记录授权与来源。
- 不伪造用户反馈、平台接入或运行结果。

## 6. 医疗口径

家庭血压阈值、警示值、危险症状和转介口径以知识卡（`knowledge_cards.json`）为准，是本课程当前采用的教学口径。知识卡中的数值来自所列指南来源，若来源或适用条件有变化，通过更新知识卡版本统一调整。
