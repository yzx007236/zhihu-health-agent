# 2026-11-15 源码发布范围

本次以工作目录中的当前代码为准，包括师生课程演示账号初始化、草木主题工作台、师生分入口、自动循环悬浮视频、训练模式、评分、课程持久化及指南经验库 v3.2。未将旧 v4.4.0 安装包冒充最新版本。

## 包含

- `web/` 当前网页、动态素材和前端检查。
- `run_local.py`：本机独立网页/API 入口。

- `zhihu/` 原始 Skill 和质控资料。
- `functions/zhihu-agent/` 云函数网关与 Node.js 依赖锁。
- `connector/server/zhihu_mcp/resources/experience.json`：原工作区实际加载的 v3.2 资源，91 卡、23 来源，保留原始字节和来源字段。
- 教材目录、可选资源接入说明、环境变量示例与自动检查配置。

经验库继续沿用现有资源加载逻辑：显式环境变量优先，其次工作区历史输出，最后使用服务内置资源。干净源码检出没有历史输出，直接使用服务内置资源；本机已有环境的使用方式保持兼容。

## 排除

本机 `.zhihu-classroom/`、`.zhihu-sessions/`、`.workbuddy/`、云端开通密钥、部署备份、日志、缓存、依赖安装目录、临时文件、商业计划书、历史发布包，以及完整教材 PDF/全文数据库。原文件留在工作目录，`.gitignore` 限制提交范围。

## 当前限制

- 本地网页使用规则对话，不具备云模型的生成对话效果。真实模型需自己的网关与密钥。
- 未安装完整教材时，教材入口如实显示不可用。
- 公开演示账号可能由其他访问者修改；自己的源码副本拥有独立账号数据库。
- 自动检查涵盖程序和模拟页面行为，不等于电脑与手机真实浏览器的视觉验收。
- 医学资料需教师核验，指南候选不参与原评分，也不能替代专业判断。
- 本次尚未为代码新增开源许可证，第三方内容权利不因公开而改变。

原 README 和部署历史保存在原工作区的 `output/`，不随源码提交。

## 发布验证适配

最新英语题库已有 `K-TEXTBOOK-EN-` 知识卡，工具验收同步接受这一前缀，并核对解析实际返回的知识卡 ID 与引用一致。前端页内指南检查在干净环境中先生成合成测试数据，避免依赖原机器的历史输出。

课程测试的临时数据库放在检出目录内：业务服务会拒绝 Linux `/tmp` 中的课程存储，测试需同样遵守这一规则；未放宽服务端的持久化保护。
